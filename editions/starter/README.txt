SOMA — calm focus planner
=========================

Thanks for buying Soma. This takes about two minutes.


1. OPEN IT
----------
Easiest: open your Soma link in Chrome, Edge or Safari:

    https://YOUR-DOMAIN-HERE

Or run this copy on your own computer: unzip the folder and double-click
index.html. (Chrome or Edge work best when opening it from a file.)


2. INSTALL IT AS AN APP (recommended)
-------------------------------------
Installing gives Soma its own window and icon, and keeps your data safer.

  - Chrome / Edge (computer): click the install icon at the right end of
    the address bar, or Menu > Install Soma.
  - Safari (Mac): File > Add to Dock.
  - iPhone / iPad: Share > Add to Home Screen.
  - Android: Menu > Add to Home screen / Install app.


3. START WITH "START HERE"
-------------------------
The "Start here" project walks you through everything in eight small
steps. Archive it when you're done.

The one thing to remember: press N (or tap +) on any screen to add a
task. Paste a list and every line becomes its own task.

The full guide (daily and weekly routines, and setups for thesis work,
studying, client work, job hunting and more) is under
More > Guide & docs, or open guide.html in this folder.


4. YOUR DATA IS PRIVATE — AND YOURS TO BACK UP
----------------------------------------------
Soma has no account and no server. Everything you type stays in this
browser on this device. Nobody else can see it, including us.

That also means clearing your browser's site data erases it. So:

  - Install Soma as an app (step 2).
  - Back up now and then: More > Settings > Export JSON. Soma reminds
    you once a week.
  - To move to another device: Export JSON on the old one, then
    Import JSON on the new one.
